# Public Assets

Положи сюда свои медиафайлы. Имена должны совпадать точно.

---

## 📸 Фотографии

Папка: `public/images/`

| Файл | Где используется | Рекомендуемый размер |
|------|-----------------|----------------------|
| `photo.jpg` | Hero (правая колонка) + About | 600×800 px (портрет 3:4) |

**Пример:**
```
public/
  images/
    photo.jpg   ← твоя фотография
```

> Поддерживаются форматы: `.jpg`, `.jpeg`, `.png`, `.webp`  
> Если файл не найден — автоматически показывается placeholder-аватар.

---

## 🎬 Видео

Папка: `public/videos/`

Создай три видеофайла — по одному на каждый язык.  
При переключении языка на сайте будет показываться соответствующее видео.

| Файл | Язык |
|------|------|
| `video-kz.mp4` | Қазақша |
| `video-ru.mp4` | Русский |
| `video-en.mp4` | English |

**Пример:**
```
public/
  videos/
    video-kz.mp4   ← видео на казахском
    video-ru.mp4   ← видео на русском
    video-en.mp4   ← видео на английском
```

> Рекомендации:
> - Формат: `.mp4` (H.264)
> - Разрешение: 1920×1080 (Full HD) или 1280×720 (HD)
> - Длительность: ~80 секунд
> - Размер файла: до 50 MB на язык (чтобы сайт быстро грузился)

---

## 👋 Приветствие (Hero)

Фотография из `public/images/photo.jpg` автоматически появится:
1. В **Hero** секции (правая колонка на десктопе)
2. В **About** секции (левая колонка)
3. Как превью в **Video** секции (размытый фон за кнопкой Play)

## ⚡ Советы по оптимизации

- Сожми изображения через [squoosh.app](https://squoosh.app)
- Видео оптимизируй через HandBrake (Preset: Fast 720p30)
- Используй `.webp` для фотографий если хочешь максимальную скорость
